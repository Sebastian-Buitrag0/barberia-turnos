## 2026-03-07 - [CRITICAL] Missing Authorization on Admin Endpoints
**Vulnerability:** Several administrative endpoints (`UsuariosController` for managing barbers and `TurnosController.RegistrarAdmin` for manually queueing clients) were missing the `[Authorize(Roles = "Admin")]` attribute, effectively making them accessible to unauthenticated users or users with insufficient privileges.
**Learning:** The application's architecture does not apply a global or controller-level authorization policy by default. In `UsuariosController`, while `ToggleDisponibilidad` correctly had `[Authorize(Roles = "Barbero")]`, the other administrative endpoints for CRUD operations on barbers were completely unannotated.
**Prevention:** Always verify that every endpoint has explicit `[Authorize]` attributes (often specifying appropriate Roles) unless it explicitly requires `[AllowAnonymous]`. In C# Web APIs without global authorization filters, omitting the `[Authorize]` attribute defaults to allowing all requests, including unauthenticated ones.
